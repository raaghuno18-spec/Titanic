# Titanic Data Analysis

Analysis and exploration of the Titanic dataset.

## Project Structure

```
├── files/              # Data files
├── images/             # Generated visualizations and plots
├── notebooks/          # Jupyter notebooks for analysis
├── LICENSE             # Project license
├── README.md           # This file
└── .gitignore          # Git ignore rules
```

## Notebooks

- **notebooks/Untitled1.ipynb** - Main analysis notebook

## Getting Started

1. Install required dependencies:
   ```
   pip install pandas numpy matplotlib seaborn jupyter
   ```

2. Navigate to the notebooks folder and open the Jupyter notebook:
   ```
   jupyter notebook notebooks/
   ```

## Dependencies

- pandas

- matplotlib
